## Gap list (build order candidates, evidence-strength ordering only — not a roadmap)

2. **Capacity-aware conversation posture** (stage 2) — read `engagementCapacity`, hold the no-advice frame automatically.
3. **Route-to-document for client-voice + memo deliverables** (stages 4–5) — routing chips; memo adoption writes KB provenance rows.
4. **Unverified-citation gate at memo/KB adoption** (stage 7) — extend NC-3e beyond title-exam.
5. **Primary-source research lane** (stage 1) — genuinely new egress scope; own engagement + triad review; do NOT fold silently into C.4–C.6.

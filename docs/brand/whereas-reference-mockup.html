Annotations — why it looks this way

  • Serif for the law, sans for the software. The wordmark, matter name, document name, and the rendered draft body are --wa-font-serif (Fraunces). Nav, metadata, labels, buttons are --wa-font-sans (Inter).
  • The recital band (Client / Parties / Source authority / Sendable) surfaces the matter's established record first — the premises everything proceeds from.
  • One accent. Oxblood (--wa-accent) does the brand + primary-action work; the comma in the wordmark is the recital mark. Everything else is paper, ink, and hairlines — no shadows.
  • Sendable = "Not yet" reads from the future export-safety gate (FOLD-SEND-1), shown here as a warn state, not a block.
  • Dark mode is the same token set inverted (toggle above) — it ships with the system, not as a separate skin.
